## Design Specificity Verdict

**LLM assessment:** Functionally specific, visually restrained. The calculator now feels clearly made for Swedish consultancy quoting: SEK, moms, admin %, rate presets, browser-local backup, margin floor and clipboard outputs are not generic SaaS filler. The visual world is still iOS-derived by decision, but this pass hardens it rather than trying to author a new identity.

**Deterministic scan:** `detect.mjs --json index.html` returned `[]`. No deterministic Impeccable findings remain.

**Visual evidence:** Rendered Chromium verification covered light/dark at 1280, 861, 390 and 320 px, seeded with realistic localStorage under `pricing.v2` and with `api.frankfurter.dev` stubbed. All eight runs reported `overflowX: 0` and no overflowers. Mobile touch targets pass at 390 and 320. The dark primary contrast failure is fixed: composited primary contrast measured 5.62:1 in dark mode and 4.94:1 in light mode. Sampled translucent fill buttons also passed AA after alpha-stack compositing.

## Overall Impression

This is now the same calculator, but with its sharp edges sanded in the places that matter. The verdict is announced, copy actions cannot produce a no-work client quote, native modal APIs are gone, dark mode has real separation, and destructive rate deletion finally names the consequence.

The remaining gap is not craft; it is recovery depth. The app prevents the worst mistakes now, but it still rarely lets the user undo them.

## What's Working

**Verdict-first status.** The margin judgement leads the Breakdown panel, gets `role=status` support, and is mirrored into a debounced `aria-live` announcement with total plus verdict.

**System-native hardening.** Save, duplicate, preset save, delete confirmations and import failure now happen in the app’s own visual system. Saving also produces both inline confirmation and a toast.

**Measured polish.** Control heights align, quote-bar text matches the rest of the UI, retainer negotiation numbers are promoted, first-run is less stranded, dark elevation is stronger, and mobile breakdown no longer overflows.

## Priority Issues

### [P2] Consequential actions are confirmed, not undoable

Rate delete, quote delete and import backup are safer than before, but recovery still depends on the user cancelling in time or having an export.

**Fix:** Add an undo toast for quote delete and rate delete. Import can remain confirmation-only because it replaces broad state.

**Suggested command:** `$impeccable harden`

### [P2] Settings-derived assumptions stay off-screen

FX date/manual override, admin %, margin floor and moms state all materially affect the quote, but most of that context lives in Settings.

**Fix:** Add a compact “pricing basis” row in the quote or breakdown panel showing margin floor, admin %, moms state and FX freshness.

**Suggested command:** `$impeccable clarify`

### [P2] Error recovery could be more actionable

Import failure now avoids raw parser messages, but copy failure and stale/blank FX still mostly state failure rather than offering a next action.

**Fix:** Give each failure one concrete recovery path: retry copy, open Settings for FX, or choose a backup file.

**Suggested command:** `$impeccable harden`

### [P3] Language remains intentionally mixed

The interface is English with Swedish tax terms. That may match the owner, but it is not yet a fully Swedish operational tool.

**Fix:** Decide deliberately whether the app chrome is English or Swedish, then keep only domain terms mixed.

**Suggested command:** `$impeccable clarify`

## Persona Red Flags

**Owner / power user:** The repeat-quote workflow is much safer, but still mouse-led. No Cmd+S, Enter-to-save outside dialogs, or keyboard acceleration for duplicate/copy.

**Colleague importing a rate card:** They can import safely now, but may not see whether FX is live, cached or manually overridden while building a foreign-currency quote.

**Accessibility-dependent user:** The core calculation loop is now announced and mobile targets pass, but undo absence still makes destructive flows stressful.

## Minor Observations

- Desktop controls are 40 px tall, while mobile controls rise to 44 px. That is acceptable for the stated touch-target issue because mobile passes, but full cross-device pointer parity would mean 44 px everywhere.
- The first-run card is better positioned, though the “Skip” path still undercuts the margin verdict’s importance.
- The footer export nudge is useful but visually distant from the settings/import/export cluster.
